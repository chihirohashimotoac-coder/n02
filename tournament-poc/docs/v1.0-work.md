## 方針（要点）

- 期 = 独立した大会（Events の 1 行。結果・順位・公開 URL を期ごとに持つ）。ディビジョン = リーグ段階のグループ（既存）。
- 期の連結・会員（期をまたぐ ID）・次期の確定記録は追加シート（スキーマ v4。追加のみ・値の移し替えなし）。
- 入替戦は新しい段階の種類 `promotion`（隣接ディビジョンの組ごとに 1 試合。既存の結果入力・特殊な結果・延期・訂正をそのまま使う）。
- 公開データ: 上限内の大会は今と同じ出力（版も同じ）。上限を超えるときだけ、ロビン・リーグ・スイス式の試合一覧を圧縮した分割行（PublicSnapshots の `EVT-….Pnn`）へ出す。
- 既存の 10 形式・作成欄の並びは変えない。「期制リーグを作成」は別の入口。
